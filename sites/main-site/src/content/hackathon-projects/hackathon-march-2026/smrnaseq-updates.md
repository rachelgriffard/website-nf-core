This project aims to improve the [nf-core/smrnaseq](https://nf-co.re/smrnaseq/2.2.4/) pipeline, by adding features and fixing bugs described in the [issues](https://github.com/nf-core/smrnaseq/issues) page.

This project will take place at the local hub in [Kansas City](https://nf-co.re/events/2026/hackathon-march-2026/university-of-kansas-medical-center).

## Goal

Update documentation and include ability to customize bowtie parameters in relation to the [smrnaseq](https://nf-co.re/smrnaseq/2.4.1) pipeline.

## Tasks

Below is a tentative list of tasks that we hope to address during the hackathon at the Kansas City local hub. This is up for change depending on the knowledge and experience of participants at the local hub.

### Allow users to customize bowtie parameters for alignment

Update based on issue [#356](https://github.com/nf-core/smrnaseq/issues/356).

### Improve documentation

Update documentation for clarity and remove issues as identified in Issue [#528](https://github.com/nf-core/smrnaseq/issues/528).
